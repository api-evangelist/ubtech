# UBTech

> UBTech Robotics (Shenzhen) builds humanoid robots (Walker series), commercial service robots (Cruzr), AI education robots and kits (Yanshee, uKit, uGOT, Jimu), and consumer smart hardware (AIRROBO). Its developer surface centers on the Yanshee educational humanoid, which exposes a device-local REST API (Open ADK) with Python and C SDKs published through the UBTEDU GitHub organization.
